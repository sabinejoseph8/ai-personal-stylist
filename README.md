# AI Personal Stylist

A mobile-first web app where you talk face to face with a lifelike AI stylist on video. A portfolio project. Sample products only: nothing here is for sale.

The plan lives in [docs/](docs/): the product spec, design, tech spec, MVP scope and the phased build plan in [docs/progress.md](docs/progress.md).

## Running it locally

1. Copy `.env.example` to `.env.local` and fill in the keys.
2. Run `npm install`, then `npm run dev`, and open http://localhost:3000.
